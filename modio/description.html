Play Melvor Idle by writing TypeScript. Your scripts run in VS Code and control your character through a typed API: skills, farming, combat, Slayer, bank and shop. 

import { run, Items, Trees } from 'melvor-script';

run(async (m) => {
  while (m.bank.count(Items.Oak_Logs) < 100) {
    await m.skills.woodcutting.cut(Trees.Oak);
  }
});

What you need

  • The desktop game (Steam). Not the browser or mobile versions.
  • Bun
  • VS Code (recommended)

Setup

  1. Subscribe to this mod and restart the game.
  2. In a new folder, run:
    bun init -y
    bun add github:c3d-gg/melvor-script#v0.7.0
    bunx melvor init
  3. Load a character, then run bun scripts/hello.ts (or press F5 in VS Code).

Good to know

  • Adds Scripted Mode, a gamemode where every action is instant, followed by a short cooldown. Normal characters work too, in real time.
  • In Scripted Mode, crops grow on their own while you do other things, in their normal time ÷ the Farming speed setting.
  • Settings are in Mod Settings → Melvor Script.
  • Scripted Mode characters need this mod to load.

Roadmap

Available now: gathering and artisan skills, farming, mastery, turn-based combat and dungeons, Slayer tasks, potions, combat spells, food, prayers and equipment, the bank and the shop.

Coming next, in this order:

  1. Astrology upgrades: spending stardust on constellation modifiers.
  2. Agility: building obstacles and pillars for your course.
  3. Cartography: surveying, paper, maps and travel.
  4. Township, with its own Township speed setting in Scripted Mode.
  5. Later: skill trees, and choosing Archaeology maps and tools.

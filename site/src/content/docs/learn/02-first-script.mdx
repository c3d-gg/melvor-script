## Line by line

```ts
import { run, Trees } from 'melvor-script';
```

**Borrow some tools.** `melvor-script` is the package you installed in lesson 1. This line takes two things from it: `run`, which connects to the game, and `Trees`, the list of every tree.

```ts
run(async (m) => {
  // ...
});
```

**Run these steps once you're connected to the game.** Everything between `{` and `}` is your script. `m` is the name for your connection to the game: through it, you reach everything. (You could call it anything. `m` is short for Melvor.)

```ts
m.log('Off to chop some trees!');
```

**Call a function.** A **function** is a named action: `log` writes a message to the Melvor Script panel. To **call** it, write its name followed by brackets, and put what it needs inside them. Here that's a piece of text. Text goes in quotes, and programmers call it a **string**.

```ts
await m.skills.woodcutting.cut(Trees.Normal, { count: 10 });
```

**Chop ten normal trees, and wait until that's done.** Read the dots like folders: in `m`, find `skills`, in there `woodcutting`, and in there the function `cut`. This time the function gets two things, separated by a comma: which tree (`Trees.Normal`), and options (`{ count: 10 }`, meaning "ten times").

`await` means **wait here until it's finished**. Chopping takes a moment; without `await`, the next line would run straight away, before the logs arrive.

```ts
m.log(`Done! Woodcutting is level ${m.skills.woodcutting.level}.`);
```

**Put a value into text.** This string uses backticks (`` ` ``) instead of quotes. Inside backticks, `${ }` gets replaced by its value, so `${m.skills.woodcutting.level}` becomes your current level, like `Done! Woodcutting is level 4.`

<Aside type="tip" title="New idea: let VS Code help">
Type `Trees.` (with the dot) and VS Code lists every tree in the game. Type `m.skills.` and it lists every skill. Hover over `cut` and it explains what `cut` does. You never need to remember exact names.
</Aside>

<Aside title="New idea: comments">
A line starting with `//` is a **comment**: a note for people, which the computer skips. The first line of the script is one. Use them to remind yourself what a part of your script is for.
</Aside>

## Common mistakes

- **Red squiggly underline?** VS Code found a mistake before you ran anything. Hover over it to see what. Usually it's a missing bracket, quote or comma.
- **Capital letters matter.** `Trees.Normal` works; `trees.normal` doesn't.
- **Forgot `await`?** The script races ahead. Here, the message would show your level from *before* the chopping.
